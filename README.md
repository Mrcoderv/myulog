# ULog
ULog is an initiative to standardize and make actionable the telemetry generated by AI systems. By introducing versioned JSON logging contracts, a normalization and enrichment pipeline, and a deterministic classification engine, ULog ensures that heterogeneous logs from APIs, LLMs, agents, and CV pipelines become reliable, auditable signals. 

## Schemas

### Agentic Contract Schema (`schemas/agentic_contract.json`)

The **Agentic Contract Schema** defines a deterministic JSON structure for logging multi-step agent workflows.  
It ensures that every step in an agentic process — tools, inputs, outputs, timing, and outcomes — can be traced from start to finish.

#### Schema Overview

Each step object in the workflow log includes:

| Field | Type | Description | Required |
|-------|------|--------------|-----------|
| `workflow_id` | `string` | Unique identifier for the overall workflow instance. | ✅ |
| `step_id` | `string` | Unique identifier for this step. | ✅ |
| `parent_step_id` | `string` | Optional reference to the parent step that triggered this one. | ❌ |
| `tool_name` | `string` | The tool or action invoked at this step. | ✅ |
| `input_summary` | `string` | Brief summary of what was input to this tool. | ✅ |
| `output_summary` | `string` | Brief summary of what was output or produced. | ✅ |
| `status` | `string` | Execution outcome — one of: `success`, `failed`, `retry`, or `timeout`. | ✅ |
| `duration_ms` | `number` | Time taken by this step, in milliseconds. Must be non-negative. | ✅ |
| `error` | `object` | Optional error object, required if status indicates a failure. Must include a `message` field. | ❌ |

#### 3-Step Sequence Example

The following example illustrates a complete 3-step agent workflow, showing hierarchical traceability between steps using `parent_step_id`:

```json
[
  {
    "workflow_id": "wf-1001",
    "step_id": "step-1",
    "tool_name": "fetch_customer",
    "input_summary": "GET /customers/142",
    "output_summary": "200 OK, customer record",
    "status": "success",
    "duration_ms": 120
  },
  {
    "workflow_id": "wf-1001",
    "step_id": "step-2",
    "parent_step_id": "step-1",
    "tool_name": "score_risk",
    "input_summary": "customer profile: id=142",
    "output_summary": "risk_score=0.21",
    "status": "success",
    "duration_ms": 95
  },
  {
    "workflow_id": "wf-1001",
    "step_id": "step-3",
    "parent_step_id": "step-2",
    "tool_name": "submit_decision",
    "input_summary": "approve if score < 0.25",
    "output_summary": "decision=approved",
    "status": "success",
    "duration_ms": 230
  }
]
