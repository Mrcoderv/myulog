# ULog
ULog is an initiative to standardize and make actionable the telemetry generated by AI systems. By introducing versioned JSON logging contracts, a normalization and enrichment pipeline, and a deterministic classification engine, ULog ensures that heterogeneous logs from APIs, LLMs, agents, and CV pipelines become reliable, auditable signals. 

## Schemas
### LLM Interaction Log (schemas/llm.schema.json)

The LLM Interaction Contract Schema defines the JSON structure for logging interactions with a large language model (LLM). 

#### Schema Overview 
| Field | Type | Description | Required |
| ------ | ---- | ------------ | -------- |
| **log_id** | string (uuid) | Unique identifier for the log entry. | Yes |
| **log_timestamp** | string (date-time) | Timestamp when the log entry was created. | Yes |
| **pipeline_stage** | string | High-level pipeline stage (`serve`, `tokenizer`, `quant`, `load`, `inference`, `rag_retrieve`, `rag_embed`, `rag_rerank`, `safety_check`, `sampling`). | Yes |
| **outcome** | string | Operation result: `success` or `failure`. | Yes |
| **model** | string | Name of the LLM model used. | Yes |
| **category** | string | Event domain (`auth`, `network`, `data`, `model`, `service`, `system`, `storage`, `scheduler`, `deployment`, `security`, `third_party`). | Yes |
| **prompt** | object | Details of the prompt sent to the LLM. | Yes |
| ├─ prompt.prompt_id | string (uuid) | Unique identifier for the prompt. | Yes |
| ├─ prompt.input_tokens | integer | Number of tokens in the input prompt. | Yes |
| ├─ prompt.prompt_text | string | The full text content of the prompt. | Yes |
| └─ prompt.parameters | object | Optional sampling parameters. | No |
| &nbsp;&nbsp;&nbsp;├─ temperature | number | Temperature parameter (0–2). | No |
| &nbsp;&nbsp;&nbsp;├─ top_p | number | Nucleus sampling threshold (0–1). | No |
| &nbsp;&nbsp;&nbsp;├─ max_tokens | integer | Maximum number of tokens to generate. | No |
| &nbsp;&nbsp;&nbsp;└─ stop_sequences | array[string] | Optional custom stop sequences. | No |
| **result** | object | Details of the model’s response. | Yes |
| ├─ result.result_id | string (uuid) | Unique identifier for the model response. | Yes |
| ├─ result.response_text | string | Full text generated by the model. | Yes |
| ├─ result.output_tokens | integer | Number of output tokens. | Yes |
| ├─ result.latency_ms | integer | Total latency of the request in milliseconds. | Yes |
| ├─ result.ttft_ms | integer | Time to first token (milliseconds). | No |
| ├─ result.anonymization_note | string | Notes about anonymization or redaction. | No |
| ├─ result.model_quality_flags | array[string] | Model quality issues (e.g., truncation, repetition). | No |
| └─ result.safety_flags | array[string] | Safety or sensitive flags (`llm`, `cv`, `pii`, `security`, `toxicity`, `hallucination`, `bias`). | No |
| **metadata** | object | Optional metadata about the log entry. | No |
| ├─ metadata.source | string | Optional source system for the log entry. | No |
| ├─ metadata.ingestion_ts | string (date-time) | Timestamp when the log was ingested. | No |
| └─ metadata.contract_version | string (SemVer) | Version of schema contract. | No |
| **meta** | object | Additional provenance and parsing info. | No |
| ├─ meta.raw_message | string | Original message (redacted). | No |
| └─ meta.parse | object | Parse adapter details. | No |
| &nbsp;&nbsp;&nbsp;├─ adapter | string | Parser adapter used. | No |
| &nbsp;&nbsp;&nbsp;├─ adapter_version | string | Version of the adapter. | No |
| &nbsp;&nbsp;&nbsp;├─ parse_ok | boolean | Indicates if parsing succeeded. | No |
| &nbsp;&nbsp;&nbsp;└─ notes | string | Optional parse notes. | No |
| **component** | string | Responsible component (`api`, `agent`, `pipeline`). | No |
| **level** | string | Log severity (`info`, `warn`, `error`). | No |
| **usage** | object | Token usage metrics. | No |
| ├─ usage.prompt_tokens | integer | Number of prompt tokens. | No |
| ├─ usage.completion_tokens | integer | Number of completion tokens. | No |
| └─ usage.total_tokens | integer | Total token count (prompt + completion). | No |
| **sampler** | object | Sampling configuration for generation. | No |
| ├─ sampler.temperature | number | Temperature (0–2). | No |
| ├─ sampler.top_p | number | Nucleus sampling (0–1). | No |
| ├─ sampler.top_k | integer | Top-k sampling. | No |
| ├─ sampler.presence_penalty | number | Penalty for token presence (-2 to 2). | No |
| ├─ sampler.frequency_penalty | number | Penalty for token frequency (-2 to 2). | No |
| ├─ sampler.stop_sequences | array[string] | Stop sequences for generation. | No |
| └─ sampler.seed | integer | Optional seed for deterministic output. | No |
| **rag** | object | Retrieval-Augmented Generation metadata. | No |
| ├─ rag.query | string | Retrieval query string. | No |
| ├─ rag.citations | string | Citations or sources retrieved. | No |
| └─ rag.stage | string | RAG stage (`query`, `retrieval`, `generation`). | No |
| **metrics** | object | Aggregated performance metrics. | No |
| ├─ metrics.average_latency_ms | number | Average latency in milliseconds. | No |
| ├─ metrics.success_rate | number | Success rate (0–1). | No |
| ├─ metrics.accuracy | number | Accuracy (0–1). | No |
| ├─ metrics.endpoint | string | Endpoint name or path (e.g., `/v1/chat/completions`). | No |
| └─ metrics.extra | object | Additional dynamic metrics (e.g., p50_ms, p95_ms). | No |
| **error_log** | array[object] | List of errors encountered. | No |
| ├─ error_log.error_code | string | Stable short code for known error. | Conditional |
| ├─ error_log.error_type | string | Type of error (validation, network, etc.). | Conditional |
| ├─ error_log.message | string | Human-readable error message. | Conditional |
| └─ error_log.timestamp | string (date-time) | Timestamp of the error. | Conditional |

**Note:** `error_log` is not required but, if present, each entry should include error_type, message, and timestamp.

###  PII & Anonymization Policy

Logs must **not** include personally identifiable information (PII) or sensitive text content.  
If a prompt or response might contain private data:

- **Truncate** long text to a short snippet.  
- **Redact** or mask names, emails, IDs, or confidential values.  
- Optionally include a small note field such as  
  `"anonymization_note": "truncated 200 chars"` to record that redaction was applied.


#### Example — Privacy-safe log entry
```json
{
  "log_id": "11111111-1111-4111-8111-111111111111",
  "log_timestamp": "2025-10-08T09:00:00Z",
  "pipeline_stage": "reference", 
  "model": "gpt-5-mini",
  "outcome": "success",
  "category": "model",
  "level": "info",
  "prompt": {
    "prompt_id": "aaaaaaaa-aaaa-4aaa-8aaa-aaaaaaaaaaaa",
    "input_tokens": 45,
    "prompt_text": "Summarize the following paragraph… (truncated)"
  },
  "result": {
    "result_id": "bbbbbbbb-bbbb-4bbb-8bbb-bbbbbbbbbbbb",
    "response_text": "The summary of the paragraph is… (truncated)",
    "anonymization_note": "truncated 200 chars",
    "output_tokens": 120,
    "latency_ms": 250
  }
}
```

### UUID Policy
- Use Version 4 UUID for all IDs (`log_id`, `prompt_id`, `result_id`)
- Generate the ID randomly at the time when the log is created. 
- All IDs must be globally unique across all logs. 
- The IDs are all lowercase strings with hyphens.
