# ULog: Complete Log Classification Categories

| #  | Main Category | Practical Category         | Description                                                                                             | Examples                                                                                                    |
|----|----------------|-----------------------------|---------------------------------------------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------|
| 1  | Model          | Model Interaction Success   | A successful response from the model that meets expected quality and performance standards.             | Normal LLM response taking 200 ms and staying within the allocated token limit.                             |
| 2  | Model          | Model Quality Event         | An output that indicates a drop in model quality, requiring review or alerting.                         | Hallucination, refusal to answer without cause, or potential bias in output.                               |
| 3  | Agent          | Tool Execution Failure      | An AI agent failed to execute an external tool call (e.g., database, external API) successfully.         | Agent receives a 500 error from the Google Search API or database connection times out.                    |
| 4  | Safety         | Safety/Policy Violation     | A clear violation of the safety or acceptable use policy, requiring immediate escalation.                | Attempted harmful/malicious prompt injection, or detected PII leakage in the response.                     |
| 5  | CV             | Computer Vision Detection   | A routine event logged by a Computer Vision (CV) pipeline.                                              | 12 objects successfully detected in the frame, or a routine tracking event.                                |
| 6  | API            | API Latency Anomaly         | The overall API Gateway response time exceeded the established threshold (slow success).                | API response time exceeded 1000 ms (soft warning limit) without a clear error code.                        |
| 7  | System         | Internal Component Failure  | A failure in a critical internal component (DB, Cache, Queue) preventing request fulfillment.            | Database connection failure, missing critical cache key, or failure to publish to a queue.                 |
| 8  | System         | Resource Depletion          | System resources (CPU, memory, disk) are critically low, threatening service stability.                  | Memory usage exceeds 95% in the classification service, or concurrent limits reached.                      |
| 9  | Agent          | Agent Step Trace            | Logging a single step within a multi-step Agent workflow for traceability.                              | Agent enters a planning step, executes a retry, or switches the workflow path.                             |
| 10 | Agent          | Agent Looping/Stall         | The agent is stuck in an unproductive loop or has stalled progress in its execution plan.                | Repeatedly executing the same “Search” step >3 times without progress, or hitting cost limits.             |
| 11 | Data           | Schema Validation Failure   | An incoming log event failed to match the defined ULog Canonical V1 schema.                             | Incoming log is missing a mandatory field (e.g., `event_source`), or has an invalid data type.             |
| 12 | Config         | Configuration Change        | An event logging a change in a critical system setting or model configuration.                          | Model version update from v2.1 to v3.0, or change in a service’s safety threshold.                         |
| 13 | API            | API Authentication Failure  | A failure related to user authentication or permissions (typically a 401/403 error).                    | Invalid access token, or missing permissions for the requested operation.                                  |
| 14 | API            | API Input Validation Error  | A failure because the request input did not match the API’s expected format (not related to ULog schema).| Missing input field (e.g., empty `user_id`), or an out-of-range value.                                     |
| 15 | Usage          | Billing/Usage Event         | Events tracking actual resource consumption for billing or budget purposes.                             | Logging the token count consumed by a response, or the cost of a specific operation.                       |
